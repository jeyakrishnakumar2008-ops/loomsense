ℹ️ About

About the smart power loom system

🏭

Smart Humidity Monitoring & Energy-Saving System

This IoT-based system monitors humidity and temperature around power looms.

A vibration sensor detects loom activity and the ESP32 controls the additional light using a relay.

When humidity becomes too high, the system alerts the user.

When the loom is not in use, the additional light can automatically turn OFF to save electricity.
